# 部门预算看板（演示数据）

一个不接真实财务系统的部门预算看板：年度预算、月度承诺、实际支出和剩余预测共享同一条时间线，可从部门总额逐层展开到项目与费用科目，比较不同预测方案下的年末余额，并逐张凭证追溯来源。

所有数字来自 `src/data/dataset.json` 里的确定性演示数据集（`scripts/generate-data.mjs`，固定随机种子），没有任何网络请求。

## 运行

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 生成 dist/standalone.html（CSS/JS 内联的单文件版）
npm run preview    # 预览构建产物
npm test           # 引擎与口径测试（17 项）
npm run check      # 44 项汇总一致性校验（KPI、表格、导出、筛选）
```

`dist/standalone.html` 可以双击直接用浏览器打开，不需要服务器。

## 五个页面与数据口径

| 页面 | 内容 |
| --- | --- |
| 总览 | 4 个 KPI、累计时间线、部门年末余额、自动提示、年末支出构成 |
| 预算对齐 | 部门 → 项目 → 费用科目三级展开表、预测假设面板、月度明细 |
| 版本与审批 | 基线版本 + 每笔调整的审批前/后金额、跨部门转移双边分录、待审批标记 |
| 异常凭证 | 未匹配部门 / 重复凭证 / 冲销记录 / 已取消采购承诺，分别列出并可追溯 |
| 方案对比 | 同一筛选范围下各方案的年末余额、差异、按部门拆分，导出差异 CSV |

### 时间线的四条线

时间线是**累计**口径：

- **累计预算**：基线按月摊 + 已生效调整从生效月起按剩余月份均摊。
- **实际支出**：截至数据截止月（2026-10）的已过账凭证，冲销以负金额计入。
- **未结承诺**：已下单、预计在截止月之后到票的采购承诺，按预计月份落位。
- **预测支出**：截止月之后的累计占用，等于实际 + 未结承诺 + 预测新增。

### 预测：节奏 + 承诺，不重复计算

对每一条预算行，未来月份按最近 N 个月的实际节奏外推（可选月增长率、部门系数），再与未来各月的未结承诺比较：

```
expected = max(run-rate 外推总额, 未结承诺总额)
预测新增 = max(0, expected − 未结承诺总额)
```

预测新增按各月 run-rate 占比分摊。这样承诺已覆盖的支出只算一次，承诺超过节奏时预测直接顶到承诺线。`includeCommitments=false` 时按不比较承诺；`includeNewSpend=false` 时预测新增为 0，年末支出只剩实际 + 承诺。

年末余额 = 年度预算 −（实际 + 未结承诺 + 预测新增）。

### 版本与审批

- 基线版本 `BV-2026-00` 由董事会审批。
- 每笔调整保存 `before / after / delta`，变动列按行展示；净额为零的调剂/转移额外显示「调剂/转移 ¥X 万」（总额不变、结构变化），避免读者误以为调整没发生。
- 待审批版本（`BA-2026-04`，12 月生效）在页面可见但**不进入生效预算**；页面提示其追加金额与预备费对应减少。
- 跨部门转移 `BA-2026-02` 两条分录金额相等、方向相反，`validateDataset` 与测试都会校验净额为 0，两边同时生效。

### 异常与冲销

- **未匹配部门**（D90）：成本中心不在主数据，不计入实际支出，保留原始凭证与原因。
- **重复凭证**：同金额/发票号/供应商的重复导入，停用但不计入实际。
- **冲销记录**：负金额凭证计入实际，与原凭证成对可追溯。
- **已取消采购承诺**：从所有承诺总额中剔除，异常页单独列出释放金额（¥420.0 万）；不需要修改任何汇总代码。
- 四个分组分别有筛选卡片，金额列右对齐，说明列可换行。

### 筛选一致性

所有视图共用同一个 `filterLines(model, filters)` 谓词，然后由 `timeline / rollup / evaluate / scenarioResults / scenarioVarianceRows` 从相同的行集合派生。筛选只改变「包含哪些行」，不改变单行数值。`npm run check` 对单部门、双部门、项目/科目组合逐一验证：

- 部门 / 项目 / 科目三级各自求和等于总计；
- 时间线最后一行等于 KPI，且等于 `evaluate()`；
- 预算 − 年末预计支出 = 年末余额；
- 各方案的部门差异行求和等于该方案总差异；
- 筛选前后同一行的预算/实际/承诺不变。

### 追溯与导出

- 每行的「凭证」按钮打开该科目的承诺与实际凭证列表；点凭证进入追溯抽屉：金额归属 → 采购单/发票/供应商/提交人/审批环节 → 重复或冲销关联凭证。
- 追溯抽屉可导出该凭证的字段 CSV（`exportTrace`），异常页的「追溯」按钮同样可用。
- 「导出预测差异」输出方案 × 部门 × 筛选条件，含相对基准差异；「导出对齐表」输出部门/项目/科目三级。

## 文件结构

```
src/lib/engine.js       纯函数预算引擎（无 React/DOM），所有数字的唯一来源
src/lib/charts.js       无依赖 SVG 图表（累计堆叠面积 + 发散条形）
src/lib/export.js       CSV 导出与筛选描述
src/components/         各页面组件与 UI 原语
scripts/generate-data.mjs   确定性演示数据（带校验）
scripts/check-consistency.mjs  汇总一致性校验
tests/engine.test.js    引擎与口径测试
```

## 设计约定

表格用万元、KPI 用万元（一位小数），所有汇总支持正负号与超支标色；图表不使用双 Y 轴，分类色固定顺序，累计层之间留 2px 表面色间隙；筛选栏固定在内容上方一行。数据截止月之前为实际、之后为预测，图上用「数据截止」分隔线标出。

演示数据、未接财务系统：页头有明确标记，所有导出文件与页面使用同一份数据。
